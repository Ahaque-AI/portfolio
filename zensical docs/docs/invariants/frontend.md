# Frontend rules

- Framework recommendation is Astro static output; confirm the decision in
  architecture docs before future scaffolding.
- Keep portfolio content and legal pages available without JavaScript.
- Use native HTML/CSS and small scripts first. Add React only for an interaction
  whose state or complexity justifies it.
- Give each step one primary action without hiding skip, back, navigation,
  privacy information, or accessible alternatives.
- Never require personal details or tutorial completion to browse the portfolio.
- Future UI verification must cover keyboard navigation, visible focus,
  mobile layout, reduced motion, direct links, and failed form submission.
- Apply the environment's relevant design skills during UI work; keep visual
  decisions in a shared design document when that work begins.
